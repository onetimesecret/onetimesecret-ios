# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as adopted across the Onetime Secret repositories. The full text
and enforcement guidelines live in the main repository:

https://github.com/onetimesecret/onetimesecret/blob/main/CODE_OF_CONDUCT.md

Reports go to `security@onetimesecret.com`.
